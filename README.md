# ESP32-CAM: живой просмотр на OLED + ASCII-арт в Telegram

Плата показывает картинку с камеры на дисплее 128×64, по нажатию кнопки
делает снимок, переводит его в псевдографику 48×16 символов и отправляет
в Telegram.

---

## Результаты работы

Снимки с камеры, которые плата отправила в Telegram:
**[папка Results](Results/)**

Что получилось:

- кадр 128×64 переводится в двоичное изображение дизерингом Аткинсона и
  выводится на OLED в реальном времени;
- тот же кадр переводится в текст из 10 символов (` .:-=+*#%@`) размером
  48×16 — это 784 байта, одно сообщение Telegram;
- на арте узнаются силуэт, лицо, контуры предметов.

### От чего зависит качество

Результат сильно зависит от освещения — камера маленькая, а символов всего
10 уровней яркости:

| освещение | что получается |
|---|---|
| свет спереди, на лицо | лицо выделяется, видны глаза и контур — лучший вариант |
| равномерный свет по всему кадру | картинка ровная, но мало контраста, детали сливаются |
| свет сзади (окно, лампа за спиной) | лицо превращается в тёмный силуэт, фон выгорает в `@` |
| объект и фон одного тона | контур теряется, получается почти однородное поле символов |
| сбоку | половина лица светлая, половина тёмная, хорошо виден рельеф |

Лучше всего работает контрастная сцена: светлый объект на тёмном фоне
или наоборот.

## Железо

| что | куда |
|---|---|
| OLED SSD1306, SDA | IO14 |
| OLED SSD1306, SCL | IO13 |
| OLED VCC | 3.3 В |
| кнопка | IO2 и GND |
| питание | 5 В на пин 5V |

## Сборка

```
плата:       AI Thinker ESP32-CAM   (FQBN esp32:esp32:esp32cam)
ядро:        esp32:esp32 3.3.11
библиотеки:  Adafruit SSD1306, Adafruit GFX, Adafruit BusIO
```

Настройки в шапке скетча:

```c
#define WIFI_SSID        "..."
#define WIFI_PASS        "..."
#define TG_BOT_TOKEN     "..."          // из BotFather
#define TG_CHAT_ID       "..."          // свой id
#define TG_VIA_PROXY     1              // 1 = через VPS, 0 = напрямую
#define TG_PROXY_HOST    "ВАШ_IP"
#define TG_PROXY_PORT    8099
```

## Перенаправитель на VPS

Если сеть не пускает к `api.telegram.org`, плата шлёт обычный HTTP на свой
сервер, а nginx в контейнере пересылает запрос в Telegram по HTTPS.
Развернуть: `bash code/vps/push.sh`.
